# DH116 厂商手册校准

日期：2026-09-10。

本次将上传的 `DH116 Series Dexterous User Manual.pdf` 与 Leadshine 官方下载中心
当日提供的 `DH116_URDF_MJCF_Files_2026_4_9.7z` 对照，并把关节学、质量和
自碰撞配置更新到 hand-only 与 xArm5 + DH116 两套模型。配色按当前决定保持不变。

- 手册给出 11 自由度、6 主动自由度、545±10 g；主动范围为拇指侧摆 0–60°、
  拇指屈曲 0–30°、食指/中指/无名指/小指屈曲 0–80°。

当前包的 MJCF 给出完整随动关系。令主动角 `x` 和随动角均以度为单位：

- 拇指：`0.0082*x² + 0.8808*x + 0.2631`；随动范围 0.2631–34.0671°。
- 四指：`0.0035*x² + 0.9206*x + 0.6344`；随动范围 0.6344–96.6824°。

旧实现采用固定 1.5 倍，最大屈曲时会让拇指多弯约 10.93°、四指多弯约
23.32°，并把拇指侧摆放宽为 -60–60°。这会扩大策略可用但真机不可达的动作空间，
也是手指更容易互穿或压入掌面的原因之一。

## 已实施修改

`dh116_joint_model.py` 集中保存厂商范围、二次曲线和质量基准。
URDF 生成器现在可用 `--refresh-generated` 重校准已有合体 URDF；hand-only URDF
从它重新切出。两套 USD 分别写入 `usd_manual_2026_04/`，自碰撞运行资产写入
`usd_manual_2026_04_self_collision/`，旧资产目录保留用于复现实验。

策略与手势仍输出 6 个命令。运行时将其展开为 11 个关节目标：6 个主动关节直接驱动，
5 个随动关节使用上述二次曲线。PhysX 原生 mimic 只能表示线性关系，因此这里采用
柔顺位置驱动逼近真实连杆约束；它复现位置关系，但不是能量守恒的机械传动模型。

厂商 URDF 的 link mass 合计 0.23767046 kg，缺少电机/电子件。生成器保留所有运动
连杆质量和惯量，将差额放在掌部并按质量比例缩放掌部惯量，使整手达到 0.545 kg。
这是手册数据允许的明确近似；缺少厂商分件惯量时无法做更精确分配。

自碰撞继续使用 1 mm contact offset、0 rest offset、8 次速度迭代。固定基座 hand-only
使用 32 次位置迭代；xArm5 合体模型在 32 次时出现一次 0.540 mm 的拇指尖/食指中节
瞬态穿入，因此提高到 64 次，而没有放宽 0.5 mm 验收线。

## 验证

七阶段 `open → rock → open → scissors → one → thumbs_up → open` 测试以 120 Hz
运行，每阶段 3 秒并逐步读取 PhysX 接触分离距离。验收要求：存在接触样本、最大穿入
小于 0.5 mm、最大关节越界小于 1°、最后 0.5 秒关节标准差小于 0.5°。

| 指标 | hand-only | xArm5 + DH116 |
| --- | ---: | ---: |
| 位置 / 速度迭代 | 32 / 8 | 64 / 8 |
| 接触组合数 | 103 | 105 |
| 采样最大接触穿入 | 0.0807 mm | 0.4064 mm |
| 最大瞬态关节越界 | 0.5963° | 0.1826° |
| 最大稳定段关节角标准差 | 0.0846° | 0.1114° |
| 验收 | 通过 | 通过 |

原始结果为 [hand JSON](dh116_manual_hand_collision_audit.json) 与
[arm JSON](xarm5_dh116_manual_collision_audit.json)，并各自带有 `.poses.json` 轨迹。
13 项单元/资产回归测试全部通过。训练烟测使用 16 环境完成 2 次 PPO 迭代、512 个
采样步，动作空间为 6、观测为 41 维，期间 `on_palm_fraction=1.0`，并成功保存 checkpoint。

旧 checkpoint 的网络形状仍兼容，但拇指侧摆的动作范围和随动角语义已经改变，不能把
旧策略在新模型上的回报直接与历史数值比较。继续训练应使用默认
`--collision_profile current` 并建立新的基线。

2026-09-10 另用旧 `model_2999.pt` 在当前模型上录制固定 seed 11、env 0 的 8 秒
[迁移回放](../renders/dh116_pen_spin_manual_calibrated.mp4)：1280×720、30 fps、H.264。
样本没有掉笔，笔中心平均高于 home 7.0 mm，笔轴相对掌面平均倾斜 6.5°；实际投影
转速为 -0.07 rad/s、累计 -0.1 圈。抽帧未见明显穿指，但它只是在掌面轻微滚动，
不代表已经学会连续转笔。

## 尚缺的真机参数

手册没有提供各 link 惯量、指垫摩擦系数、接触柔顺性或间隙。当前碰撞验证只覆盖固定
动作序列和现有 convex-decomposition collider，不代表任意策略动作都绝无视觉网格相交。
手册图片显示的黑色掌面/指端区域不能从当前单块 STL 自动分出独立材料，配色本轮保持原样。
后续若拿到 CAD 材料分区、摩擦测试或分件惯量，应以真机数据替换这些近似。
