# xArm5 + Leadshine DH116 (right hand)

One URDF / one USD articulation: UFactory xArm5 -> frustum flange adapter ->
Leadshine DH116-R dexterous hand.

## What was changed relative to the vendor DH116 URDF

- Joint limits use the 2026 manual/package values: thumb side swing 0..60
  deg, thumb flexion 0..30 deg and four-finger flexion 0..80 deg. Passive
  limits come from the package's MJCF equality curves.
- Six policy/gesture commands expand to eleven joint targets. The thumb
  follower uses `0.0082*x^2 + 0.8808*x + 0.2631` degrees; each other finger
  uses `0.0035*x^2 + 0.9206*x + 0.6344` degrees, where `x` is the active
  joint angle in degrees.
- Effort / velocity limits set to 2 N.m / 3 rad/s so the drives are not
  zero-limited.
- Moving-link inertias remain from the vendor URDF. Missing motor/electronics
  mass is assigned to the palm so the generated hand totals the manual's
  nominal 0.545 kg instead of the mesh-only URDF's 0.23767046 kg.

## Known gaps

- PhysX only supports linear mimic joints. Runtime code sends the exact
  quadratic follower target through a compliant drive; it is a servo
  approximation of the linkage rather than a mechanical constraint.
- The manual gives total mass but no link-level inertias, so the extra mass
  is an explicit palm approximation.
- The current visual mesh/material split cannot reproduce the black palm pads
  and shell regions shown in the manual. Colors remain unchanged for now.
- The manual gives no pad friction coefficient, so contact friction still
  needs real-hand or vendor data for calibration.
